# Jost webfonts

This directory contains the Latin and Latin Extended WOFF2 subsets for Jost
Medium (500) and Jost Medium Italic (500).

- Typeface: Jost
- Upstream: https://github.com/indestructible-type/Jost
- Webfont source: https://fonts.google.com/specimen/Jost
- CSS request used to select the subsets: `Jost:ital,wght@0,500;1,500`
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`

The Chinese glyphs used by the site intentionally continue through the CSS
fallback stack because Jost does not provide CJK coverage.
